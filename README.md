# For My Chotiii — React story cards

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown by Vite.

## Add your song
Place an audio file you have permission to use at `public/song.mp3`.
The app loops it and starts at 65% volume (adjustable from the bottom slider).
Browsers usually block autoplay until the visitor interacts with the page, so the first Next/music tap starts playback.

## Customize
- Edit the `slides` array in `src/main.jsx` to change the story text.
- Change pink colors in `src/style.css`.
- The card deck loops forward and backward; swipe on mobile or use Next.
